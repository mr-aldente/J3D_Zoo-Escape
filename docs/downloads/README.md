# Téléchargement du jeu

Placez ici l'installateur Windows après compilation :

```bat
cd installer
build.cmd
```

Le script copie automatiquement `ZooEscape_Setup.exe` dans ce dossier. Le site (`docs/index.html`) pointe vers :

`downloads/ZooEscape_Setup.exe`

Pour GitHub Pages, publiez le dossier `docs/` (y compris ce fichier une fois généré).
